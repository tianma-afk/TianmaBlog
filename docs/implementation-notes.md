# 第一阶段：剧场书房

## 已确认的需求

使用 Nuxt 构建个人博客，之后部署到 Vercel。首次访问先看到舞台幕布；启幕后正对阶梯状书架；点击书本进入简历、博客、小说、日志等页面。

## 第一版可调整的设计假设

- 暖暗色剧场、深红幕布、三层木质阶梯；无外部图片、远程字体或 3D 引擎依赖。
- 幕布上只显示英文书法字「Life is a play」，不显示其他文字或按钮。访客点击幕布任意位置或按 Enter / 空格启幕，Esc 可跳过动画；字体 Pinyon Script 采用内联 base64 与预加载，避免网络延迟导致首屏后备字体跳变（FOUT）。
- 直接访问网站或刷新首页时，幕布始终保持合上状态；在同一次站内访问中翻阅书本返回书架时保持展开。点击「退出」后合拢两侧幕布，等两侧 transform 动画都完成后才恢复艺术字；减少动态效果时直接回到开场。主动清理历史本地存储标记。
- 本地存储不可用时，只记住当前站内浏览状态。
- 四个栏目先建立可访问的占位页，真实履历、文章和章节待提供，不生成虚构内容。

## 技术事实核验（2026-11-04）

- npm registry 查询 `nuxt` 的稳定版本为 4.6.4，其 engines 为 `^22.22.3 || ^24.15.0 || >=26.0.0`。本项目使用 Node 24.15.0 或更新的兼容版本。
- 本地原始 Node 为 24.11.0，因此本次用 npm 缓存内的临时 Node 24.15.0 验证，不修改系统 Node。
- Nuxt 支持 Vercel 部署并提供自动识别。当前不硬编码 Nitro preset，保留本地 Node 生产预览与 Vercel 平台自动选择能力。
