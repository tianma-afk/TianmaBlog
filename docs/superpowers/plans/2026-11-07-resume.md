# Resume implementation plan

> **For agentic workers:** Use superpowers:executing-plans inline. Track steps with checkboxes.

**Goal:** Build the personal resume in the visual style of cv.zhilu.cyou, accessible at /resume and the root of a cv subdomain.

**Architecture:** Keep the existing Nuxt 4 application. Store verified resume content in typed data, render it with isolated resume components/CSS, and select the resume at the cv hostname without a redirect. Keep the original reading room as a component so its behavior stays unchanged.

**Tech Stack:** Nuxt 4, Vue 3, TypeScript, CSS, Playwright.

**Spec:** User request dated 2026-11-07; local DOCX; https://cv.zhilu.cyou/ and the MIT-licensed L33Z22L11/zhilu-cv repository.

## Global constraints
- Match the reference: pale #f7faff canvas, white rounded paper, approximately 19cm content width, 14.8px sans text, centered name, two-column metadata, ruled section headings, gray project bars.
- Preserve source facts, contact details and project responsibilities; do not invent dates, internships, numeric achievements or project links.
- No new runtime dependencies or remote fonts, icon requests, analytics or contact form.
- Keep the existing reading-room theme isolated from resume styles.
- Make cv host root SSR-rendered; keep /resume working and non-cv roots unchanged.
- DNS/provider actions require a known parent domain and existing provider access; never claim live deployment without verification.
- Retain MIT attribution for adapted reference layout.

## Review focus

- cv host root refresh: resume HTML and SEO, not the curtain or bookcase.
- Dark system preference and print: readable contrast, white print canvas, hidden controls, no clipped content.
- Return from /resume: bookcase remains open; other section pages remain unchanged.
